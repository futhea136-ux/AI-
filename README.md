# AI 小秘

AI 小秘是一个免费静态原型：同屏语音输入、日历查看和日程管理。当前版本可部署在 GitHub Pages，电脑端和手机端都能通过浏览器访问，也可在支持 PWA 的浏览器中安装为应用。

公开体验地址：

https://futhea136-ux.github.io/AI-/

## 当前功能

- 语音或文字创建日程
- 月视图、周视图、日程列表
- 日程新增、查询、修改、删除
- 标记已完成，并保留在日程中
- 待确认事项，用橙色虚线状态表示
- 重复日程：每天、每周、工作日、每月
- 提醒：开始时、提前分钟、提前小时、提前天数
- 页面内提醒和可选浏览器通知
- 本地搜索日程
- JSON 备份与恢复
- ICS 日历文件导出
- PWA 安装入口和安装说明
- 离线/本地状态说明
- 操作日志查看、手动清空，并自动清理 7 天前记录

## 数据说明

当前版本不使用账号、不使用云数据库，也不接入真实 AI 服务。日程、日志、提醒送达记录都保存在当前浏览器本机的 `localStorage`。

这意味着：

- 不登录也能用
- 不会自动上传数据
- 换浏览器或换设备后看不到原来的日程
- 更换设备需要先导出备份，再在新设备恢复
- 清理浏览器数据可能会删除本地日程

## 提醒限制

这是 GitHub Pages 上的免费静态原型，没有后端服务器。

因此：

- 页面打开时可以检查提醒
- 已安装应用可运行时也可以检查提醒
- 浏览器系统通知需要用户授权
- 网页完全关闭后的后台定时提醒不保证触发
- 手机系统级长期后台提醒需要进入正式产品阶段

## 验收清单

建议按下面步骤验收：

1. 打开公开页面并确认日历显示当前月份。
2. 说或输入：`明天晚上七点十五分提醒我烧水`。
3. 确认卡出现后点击 `确认添加`。
4. 在日历中确认日程已出现。
5. 搜索 `烧水`，确认可以跳转到对应日期。
6. 修改日程时间或标题，确认日历同步更新。
7. 标记完成，确认日程保留但状态变为已完成。
8. 打开提醒中心，确认提醒状态可查看。
9. 打开本地说明，查看最近操作日志。
10. 清空日志，确认日程不会被删除。
11. 导出 JSON 备份，再恢复一次测试数据。
12. 尝试浏览器安装入口或安装说明。

## 本地运行

```powershell
pnpm install
pnpm dev
```

打开浏览器访问：

```text
http://localhost:3000
```

## 验证命令

```powershell
pnpm test
pnpm typecheck
pnpm build
```

## 原型收尾边界

当前版本适合作为免费可体验原型。若继续做正式产品，下一阶段通常包括：

- 账号登录和多设备同步
- 后端数据库
- 真实 AI 语义模型
- 手机后台可靠提醒
- Google Calendar / Outlook Calendar 同步
- 用户权限和隐私设置
