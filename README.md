# AI 小秘

AI 小秘是一款支持手机端和电脑 Web 端的智能日程助手。用户可以在查看日历的同时，通过语音或文字创建、查询、修改和删除日程。

## 首版范围

- 语音与文字输入
- 月视图、周视图和日程列表
- 日程新增、查询、修改和删除
- 重复日程
- 浏览器通知与页面内提醒
- AI 自然语言解析与信息追问
- 已确认、待确认和已完成三种日程状态
- 手机端与电脑端共用账号和日程数据

## 已确认的交互方向

- 手机端：日历为主体，底部固定语音按钮，AI 解析结果以确认卡片展示。
- 电脑端：左侧 AI 对话区、中间日历、右侧日程详情。
- 视觉方向：专业效率风与智能对话风融合。

## 当前阶段

Next.js、React 和 TypeScript 项目框架已建立，B+C 融合界面已迁移为正式 React 组件。

当前已实现浏览器本地日程管理：

- 选择日期并查看当天安排
- 前后月份切换及返回今天
- 月视图、周视图和日程列表视图
- 新增、修改和删除日程
- 已确认、待确认和已完成状态切换
- 每天、每周、工作日和每月重复
- 重复日程仅修改或删除本次
- 浏览器本地持久化保存

免费语音助手原型已实现：

- 使用浏览器提供的中文语音识别
- 无语音支持时使用文字输入
- 识别今天、明天、后天、星期及具体日期
- 识别中文数字时间、提醒和重复规则
- 支持创建、查询、修改、删除和标记完成
- 识别“可能、暂定、待确认”等不确定表达
- 日期、时间或事项缺失时继续追问
- 执行变更前展示确认卡

当前采用纯本地数据方案，不使用账号或云数据库：

- JSON 完整备份导出
- JSON 备份恢复，恢复前二次确认
- 标准 ICS 日历文件导出
- ICS 保留日期、时间、状态、提醒和重复规则
- 可手动将备份文件传到其他设备恢复

提醒能力：

- 页面打开期间每 15 秒检查一次到期提醒
- 页面内提醒无需浏览器授权
- 可选开启浏览器系统通知
- 支持开始时、提前分钟、提前小时和提前天数
- 重复日程按每次发生时间提醒
- 已完成和时间待定的日程不会触发
- 已送达提醒会记录，避免重复弹出


打开浏览器访问 `http://localhost:3000`。
